# 宽基 ETF 量价跟踪器

用 20 只宽基 ETF 的公开行情，观察「平准类资金」（市场俗称国家队）有没有在动手。

纯静态、零依赖、零后端：一条命令抓数据，双击 HTML 看结果。不需要 token，不需要注册，不需要装任何库。

```bash
cd app
python update_data.py      # 约 25 秒
# 然后双击 app/index.html
```

---

## 它能给你什么

一张页面，四件事：

| 指标 | 回答的问题 |
|---|---|
| **成交额放大倍数** | 今天的量，是 20 日均量的几倍？≥1.8× 算强信号 |
| **主动净买入** | 按外盘/内盘推算，今天的成交是买方主导还是卖方主导？ |
| **份额变化** | 有没有真金白银在申购（一级市场），而不只是二级市场换手？ |
| **尾盘占比** | 放量的钱是收盘前托底进来的，还是早盘抢筹冲进来的？ |

四者组合起来做判定：**放量 + 净买入为正 + 尾盘占比升高**，才是典型的托底形态；**放量 + 普涨 + 早盘放量**，多半只是情绪修复，跟托底没关系。

> 这个区分是整张页面的核心。市场上大多数「国家队入场了」的说法，只看了第一条。

---

## 页面怎么读

**顶部状态标签**告诉你数据状态，先看这个：

| 标签 | 含义 |
|---|---|
| 已收盘 | 用的是收盘后的完整快照，数字最准 |
| 盘中 | 用实时行情叠加，倍数已按同时点进度折算（见下文） |
| 非交易日 | 沿用最近一个交易日的快照 |

**四张指标卡**是池内合计值，回答「整体有没有异动」。

**表格**逐只列出 20 只 ETF，`core` 分组是真正的权重品种（沪深300、上证50、中证500、中证1000、科创50、创业板等）。看判定结论时，权重品种的反应比小票重要得多。

**加仓指数**以你第一次运行脚本那天为 100，追踪池内总份额的相对变化。它需要每天积累，跑满 20 个交易日才有形态。

## 数据从哪来

两个免费公开接口，都不需要鉴权：

- **新浪 5 分钟 K 线** —— 主数据源。每根 K 自带 `amount`（成交额），48 根求和就是当天精确成交额，不用「成交量 × 均价」近似。
- **腾讯行情快照** —— 现价、涨跌幅、外盘/内盘、场内份额。

字段位置、单位陷阱、备用写法都在 [`docs/02_指标口径与实现.md`](docs/02_指标口径与实现.md)。

## 一个例子：怎么用这张表判断

拿 2026-11-04 这天说。

那天池内放量 **1.74×**，主动净买入 **+184.51 亿**。按四象限，这落在「有护盘迹象」区间。但翻一下明细，结论会反过来：

| 看的维度 | 数值 | 说明什么 |
|---|---|---|
| 池内加权涨跌 | **+3.71%** | 是普涨日，不是权重承压 |
| 中证1000 / 科创50 / 创业板 | +4.6~4.8% / +10.5% / +6.6% | 涨的全是中小盘和科技 |
| 沪深300 / 上证50 | +2.0% / +1.35% | 权重几乎没动 |
| 上证180金融ETF | **−0.73%** | 大金融还在跌 |
| 尾盘半小时成交占比 | **13.1%**（20 日均值 17.0%） | 钱是早盘进的，不是收盘前托的 |

净买入前五名合计约 150 亿，占全部净买入 82%，但没有一只落在真正的权重品种上：上证50ETF 只有 0.93× 且缩量，沪深300ETF华夏 0.60×。

**结论**：这是科技与中小盘领涨的情绪修复性放量。典型的托底形态是「缩量下跌 + 权重 ETF 放量 + 连续三天以上」，不是「普涨 + 全线放量 + 一次到位」。

单看倍数会误判，这是这个工具最需要小心的地方。

## 边界

写在这里，免得以后自己忘了，也免得别人拿它当投资建议。

- **名单不可验证。** 2026-05-01 起，上市基金不再强制披露前十名持有人。所以池子里的「汇金持仓」是历史标签，不是当前持仓；所有「国家队」推断，本质只是「有人在买宽基 ETF」，至于是谁，无从确认。
- **份额变化不等于国家队。** 申购方可能是保险、私募、量化，也可能是散户。
- **主动净买入受行情影响。** 单边上涨日成交多在卖价完成，该指标天然偏正；下跌日天然偏负。它适合看背离（放量但净卖出），不适合单看绝对值。
- **加仓指数要攒数据。** 从你第一次跑脚本那天算起，无法回溯。
- **接口随时会变。** 免费公开接口没有 SLA。哪天新浪挂了，改 `update_data.py` 里 `fetch_5min()` 的 URL 即可，其余不用动。
- **不构成投资建议。** 数据可能有延迟、缺失、口径差异，一律以基金公司公告和交易所披露为准。

如果要做成对外可访问的页面，建议加 basic auth 和 `noindex`——内容是「用量价推测资金行为」，公开可检索容易被当成投资建议或政策解读。
